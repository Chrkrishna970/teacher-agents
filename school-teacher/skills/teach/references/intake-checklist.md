# Intake checklist (gate)

Collect each item; work it out from the material where you can; ask only for the rest. Defaults in brackets.

## 1. Main material
- Material location: files / folder / photos / pasted text
- Subject · class/grade · board/curriculum (e.g. CBSE, ICSE, AP SCERT, TS SCERT, state board) · medium of instruction
- Book name and edition; lesson/unit list (from contents page)
- Lessons in scope this time [one lesson first, so the teacher can check the style]
- Page ranges per lesson (printed page numbers vs PDF page numbers)
- Readability: is the PDF text layer usable? If not → render pages to images

## 2. Required outputs
- Notes document (.docx) [yes]
- Slide deck (.pptx) [yes]
- Question paper(s) (.docx + PDF) [yes, 1]
- Answer key (.docx + PDF) [yes]
- Explanation languages in notes [medium + students' home language + English]
- Slides per lesson [12–18]

## 3. Question-paper structure and count (per paper)
- Number of papers / sets [1]; fresh questions in each? [yes]
- Total marks [20] · time [marks ≤ 20 → 30 min; 25 → 45 min]
- Sections: type × count × marks each — MCQ, fill in the blanks, match, true/false, one-word, short answer (2), long answer (4–5, with OR), diagram, numerical, comprehension passage
- Check that marks add up; if not, offer splits
- Paper language and instruction-translation language [medium; one line in home language]

## 4. Must-include topics (loop with main-teacher SCAN)
- Teacher's list of elements every paper must test (offer a preset from presets.md)
- Always: the lesson's own story/concept/process + author/source details
- Run SCAN → concepts.md → show ✅/⚠️/❌ → keep/drop/replace → repeat until confirmed
- Extra concepts from the scan worth testing?

## 5. Other important things
- Layout: easy reading + low printing cost (layout-standards.md) [yes]
- Max pages per paper [as few as possible without cramping; 20–25 marks usually ≤3 A4]
- School name / exam name in header [blank line to fill]
- Difficulty mix [50% easy / 35% medium / 15% thinking, within the lesson]
- Textbook share [≥ 60% of marks from textbook exercises]
- Avoid repeating earlier papers for this lesson [yes]
- Answer key detail [answer, source page, element, difficulty, marking split, coverage table]
- Teacher to confirm answers the book gives no key for [yes, list them]
- Deadline / printing date
