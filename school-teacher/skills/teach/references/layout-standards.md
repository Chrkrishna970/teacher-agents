# Printed question paper — layout standards

Two goals, in this order: **1. easy for students to read and write in · 2. cheap to print (fewest pages).** Never trade (1) for (2).

## Easy to read and write
- **MCQ:** options BELOW the question in 2 rows — (a)(b) on row 1, (c)(d) on row 2 — wide gap between columns. Very long options: one per line. Answer bracket `(    )` at the right end of the question line.
- **Rough work:** ~0.8–1 cm empty space after every objective question.
- **Fill in the blanks:** long blanks; NO word choices next to the question. Put all choices in a small grey **"Hints"** box at the END of the section (smaller font, numbered by question, two columns). The instruction line says the hints are at the end.
- **Written answers:** ruled answer lines under the question — about 3 lines for a 2-mark answer, 8–10 for a 5-mark answer (match the "write in N lines" wording).
- **Long answer with OR:** main question, centred "OR / अथवा", second choice; marks at the right of each.
- One clear section header bar per section with its marks, e.g. "(7 × 1 = 7 marks)".
- Font: one that covers every script used (Windows: **Nirmala UI** for Latin + Indian scripts); ~11.5 pt questions, ~9.5 pt hints. No italics for Indian scripts (Word slants them badly).
- Underline only the word a question calls "underlined"; bold for emphasis.

## Cheap to print
- Header compact: school line, one title line (exam · class · lesson · paper no.), one line for name / class / roll no. / date, one line for marks / time.
- Instructions: one short paragraph + one line in the students' home language.
- Margins ~1.5 cm, A4 portrait, page numbers "page x / y" in the footer.
- No forced page breaks, except when a section would otherwise split away from its hints box.
- No nearly empty last page; target ≤3 A4 pages for a 20–25 mark paper (2 sheets double-sided).
- Report the page count after building.

## Answer key
- Tables: Q | answer | source (textbook p.__ / new) | element | difficulty | note.
- Model answers + marking split for every written answer (e.g. any 2 correct points × 1 mark; long answer content 3 + language 1 + presentation 1).
- Element-coverage table and an honest note on overlap with earlier papers.
